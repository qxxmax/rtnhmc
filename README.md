# rtnhmc: round-trip updates of learned nonequilibrium Hamiltonian paths

Neural nonequilibrium Hamiltonian Monte Carlo (NHMC) learns a path of stochastic Hamiltonian stages that carries a
simple initial field to configurations of a lattice field theory. This repository contains the code for using such
learned paths inside an exact Markov chain. A round-trip update walks back from the current configuration along a
reverse path to an intermediate field, generates a new configuration forward from the same field, and accepts it with
a Metropolis test that preserves the target distribution. Its mean acceptance follows erfc(σ/2), where σ² is the
conditional work variance at the shared intermediate field; σ² can be measured on forward paths before any Markov
chain is run. In two-dimensional φ⁴ theory, σ² is roughly proportional to the volume and decreases with the number of
path stages T roughly as T^-0.8. The autocorrelation time of full round trips follows τ_int ≈ C(1/α − 1/2), so keeping
the acceptance requires T ∝ V^1.25 (extrapolated from L ≤ 16). Path-IMH, which uses learned paths as independent
proposals, holds on large-weight states for long times, whereas round trips, which redraw the reverse path at every
step, do not. Bridge (BAR) free energies from frozen models transferred to 512 × 8 lattices remain accurate at
κ = 0.20 and 0.30, and the same relations hold for full round trips on CMCD and DBS paths.

## Quick look

`rtnhmc_demo.ipynb` walks through one trained model (L = 8, κ = 0.27, T = 16): it measures σ² on forward paths,
predicts the acceptance, runs short path-IMH, full and truncated round-trip chains, and compares acceptance and τ_int
with the predictions and with the long chains of the paper. The notebook is generated by `code/build_notebook.py`;
`jupyter nbconvert --to notebook --execute rtnhmc_demo.ipynb --output rtnhmc_demo_executed.ipynb` writes an executed
copy.

## Run it yourself (CPU is fine)

```bash
conda env create -f environment.yml      # or: pip install -r requirements.txt (Python 3.10-3.13)
conda activate rtnhmc
python code/build_notebook.py rtnhmc_demo.ipynb
jupyter lab rtnhmc_demo.ipynb
```

- **Hardware:** without an NVIDIA GPU the notebook uses a laptop-sized setting (`MODE` in the first code cell);
  quick mode is sized for about 10–15 minutes on a laptop CPU.
- **Model:** `model/` holds the weights (`kernel_final.pt`, 0.6 MB), the configuration and the training logs; all
  other models are in the Zenodo record.
- **Precision:** float32 throughout; TF32 is switched off, so that reverse stages invert forward stages.

## What the notebook shows

1. **The model and the three updates:** the path work W, path-IMH, full round trips (RT) and truncated round trips
   through stage s = 12 (pRT, the last four stages redrawn).
2. **Forward paths:** effective sample fraction of the weights, Pareto k̂, SNIS log Z.
3. **Conditional work variance:** σ_s² for s = 0 and s = 12 from 16 continuations per intermediate field, against
   the stored jackknife values, and the predicted acceptance erfc(σ_s/2).
4. **Short chains** of the three updates from forward-path starts.
5. **Acceptance and τ_int(|m|)** against erfc(σ/2), against C(1/α − 1/2) with C = 1.18, and against the paper's long
   chains of the same model; the longest rejection runs of path-IMH and of round trips.
6. **Free energy:** SNIS, one-way reverse and BAR bridge estimates of log Z from the RT chain, against
   thermodynamic integration of Wolff / HMC data.
7. **Paper figures:** how to redraw them from the Zenodo record.

## Reproducing the full pipeline

All commands run from the repository root. Download and extract the Zenodo record (its README gives the commands) and
set `export NHMC_ROOT=/absolute/path/to/extracted/record`. The as-executed command lines of every run are in
`code/tasks/cluster/` (machine-specific paths).

1. **Train a native φ⁴ model** (one per L and κ; CPU or GPU):

   ```bash
   python code/train_phi4.py --kernel nhmc_resid2 --use-z2 --odd-nets --fixed-pflip 0.5 --L 8 --n-leapfrog 5 \
       --batch-size 48 --buffer --buffer-start 1000 --buffer-chains 64 --buffer-every 2 --buffer-size 20000 \
       --buffer-weight 1.0 --kappa-min 0.27 --kappa-max 0.27 --num-steps 16 --epochs 20000 --seed 0 \
       --device cuda --save-dir runs/L8_k0.27_buf_s0
   ```

2. **Forward-path evaluation** (ESS, SNIS log Z, k̂; 262144 paths):

   ```bash
   python code/exp_forward_eval.py --run-dir runs/L8_k0.27_buf_s0 --n 262144 --batch 16384 --kappas 0.27 --out runs/L8_k0.27_buf_s0/eval_N262144.json
   ```

3. **Conditional work variance** σ_s² with jackknife:

   ```bash
   python code/exp_wtail_var.py --run-dir runs/L8_k0.27_buf_s0 --kappa 0.27 --n 16384 --R 16 --threads 4 --out runs/sigma2/L8_k027.json
   ```

4. **Long chains** (four chains, adaptive length; `--method imh | rt | rtp:12`; `--imh-pregen` for path-IMH;
   `--L` / `--L2` to transfer a frozen model to another lattice):

   ```bash
   python code/exp_chains.py --kind phi --run-dir runs/L8_k0.27_buf_s0 --ckpt kernel_final.pt --kappa 0.27 --method rt \
       --n-chains 4 --n-start 10000 --n-max 200000 --device cpu --threads 1 --out runs/chains/L8_k027_rt.json
   ```

5. **Free energy:** chains with reverse records and forward works, then the estimators:

   ```bash
   python code/exp_logz.py --run-dir runs/L8_k0.27_buf_s0 --ckpt kernel_final.pt --kappa 0.27 --method rt --n 50000 --n-fwd 65536 --out runs/logz/L8_k027_rt.json
   python code/free_energy.py runs/logz/L8_k027_rt.npz
   python code/exp_raw_snis.py --run-dir runs/R64x8_k020_buf_s0 --L 64 --L2 8 --kappa 0.20 --n 65536 --out runs/raw_snis/R_64x8_k020.json
   ```

6. **References:** Wolff and HMC on the coupling grid (`code/baselines/wolff_hmc/spin/run_spin.py`, lines in
   `code/tasks/cluster/tasks_ti_wolff_hmc.txt`), thermodynamic integration and AIS:

   ```bash
   (cd code/baselines/wolff_hmc/spin && python run_spin.py --theory phi4 --L 16 --params kappa=0.27 lam=0.022 --algo wolff --n-samples 100000 --burn 5000 --seed 20261106 --tag L16_k027_wolff --out-dir ../../../../runs/wh)
   python code/exp_ti_logz.py               # reads $NHMC_ROOT/results_sync/revision/ti_wolff_hmc/, writes ti_logz.csv here
   python code/exp_ais_logz.py --L 8 --kappas 0.20,0.27,0.30 --out runs/logz_ref_L8.json
   ```

   HMC + global Z2 flip reference values of |m|, m², S/V (lines in `code/tasks/cluster/tasks_E1_refs.txt`,
   `tasks_E1grid_refs.txt`, `tasks_hmc_refL.txt`):

   ```bash
   python code/baselines/hmc_z2/phi4_hmc_z2.py --L 16 --kappa 0.27 --lam 0.022 --out runs/hmc_L16_k027.json
   ```

7. **Controls without learned parts:** `code/exp_nehmc.py`, `code/exp_nehmc_grid.py` (nonequilibrium HMC) and
   `code/train_protocol.py` (protocol parameters only).

8. **CMCD / DBS** (`code/baselines/cmcd_dbs/`): train with
   `python code/baselines/cmcd_dbs/cmcd_phi4.py --alg cmcd --kappa 0.27 --T 80 --dt 0.1 --iters 10000 --batch 500 --lr 5e-4 --out runs/cmcdz2_k0.27`,
   chains with `python code/exp_chains.py --kind cmcd --model runs/cmcdz2_k0.27/model.pt --kappa 0.27 --method rt ...`,
   refined paths with `REFINE_MULT=4 python code/baselines/cmcd_dbs/longchain_refined.py --kind cmcd ...`, log Z with
   `code/exp_logz_udb.py`.

9. **DW and LJ13** (`code/baselines/dw/`, `code/baselines/lj13/`): training with `dw_v2/train_block_dw_nhmc.py` and
   `PYTHONPATH=code/baselines/lj13/particle python code/baselines/lj13/train_lj_rtbuf.py`, chains with `python code/exp_chains.py --kind dw | lj ...`, references with
   `dw_hmc_flip.py` and `lj13_pt_reference.py`. The LJ13 test and validation configurations of Köhler, Klein and Noé
   are not redistributed; `lj13_compare.py --refs` expects `test_split_LJ13-1000.npy` from their dataset.

10. **Timing table** (Appendix B): `code/exp_timing.py`, driven by `code/tasks/timing/run_bench.sh`.

11. **Figures and tables** (inputs from `$NHMC_ROOT`; the scripts import their helper modules from the record and
    write PDFs into the record tree, so keep its layout):

    ```bash
    bash figures/zenodo_20261118/redraw_all.sh /tmp/redraw python      # figures of the 2026-11-18 record; plotted data in /tmp/redraw
    python figures/figs_20261119u6/fig_logz_u6.py                       # fig:nhmc_square_logz and fig:logz_rev
    python figures/zenodo_20261118/tables/make_tab_tau_per_size.py      # and the other table scripts below
    ```

12. **Tests** (CPU; both files together take under an hour on 8 cores): `python -m pytest -s tests`, or
    `python tests/test_tau_rule.py` and `python tests/test_reversibility.py` separately.
